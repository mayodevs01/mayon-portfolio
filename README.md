# Mayon Portfolio

A complete React and TypeScript portfolio for MAYON, an independent web and software studio. The site includes a reference-matched dark portfolio, six case studies, and six distinct interactive concept demos.

## Run locally

```bash
npm install
npm run dev
```

Production check:

```bash
npm run build
```

## Routes

Portfolio pages: `/`, `/work`, `/services`, `/industries`, `/about`, and `/contact`.

Concept demos: `/demos/real-estate`, `/demos/ecommerce`, `/demos/restaurant`, `/demos/local-service`, `/demos/professional`, and `/demos/saas`.

All demo businesses, people, reviews, case studies, properties, products, results, reservations, orders, and accounts are fictional and provided only to demonstrate interface behavior.
